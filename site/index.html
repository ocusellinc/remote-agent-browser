# A BROWSER FOR AGENTS

Run agent-browser in an isolated Vercel Sandbox. Chromium and the CLI are already inside the container image, so every browser starts from the same clean environment.

## INSTALL

npm install remote-agent-browser @vercel/sandbox

## BASIC USAGE

import { createAgentBrowser } from 'remote-agent-browser'

const browser = await createAgentBrowser()

try {
  const { results } = await browser.run([
    ['open', 'https://example.com'],
    ['snapshot', '-i', '--json'],
  ])

  console.log(results[1].stdout)
} finally {
  await browser.close()
}

Authentication is provided by VERCEL_OIDC_TOKEN. On Vercel it is available automatically; locally, pull it from a linked project.

## COMMANDS

browser.run(commands)
Run several agent-browser commands in one session.
browser.exec(command)
Run one command with arguments and flags.
browser.snapshot(url)
Open a page and return its interactive JSON snapshot.
browser.screenshot(url)
Open a page and return a PNG buffer.
browser.close()
Close the session and stop the Sandbox.

## CONTAINER IMAGE

The default is remote-agent-browser:latest. Use an immutable tag or digest in production. 

const browser = await createAgentBrowser({
  image: 'remote-agent-browser:v1',
})
